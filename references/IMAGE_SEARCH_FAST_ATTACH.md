## 3. 웹 Gemini 초고속 첨부 프로토콜 (`Part B 3차` 표준 · 검색 0회 · 43초 컷)

### Step 0. `00_제미나이_첨부용_2장` 선행 복사 (Drive `최근 문서함` 최상단 노출 트리거)
- 작업 시작 즉시 확정된 2장을 현재 상품 폴더의 `00_제미나이_첨부용_2장\`에 아래 이름으로 복사(또는 덮어쓰기)하여 Google Drive **최근 문서함(Recent)** 최상단에 즉시 노출시킨다:
  - `01_Image1_룩북메인모델<N>.png`
  - `02_Image2_<색상>_<사이즈>_행거샷_합격본.png`

### Step 1. 일반 Chrome (`chrome-devtools` MCP) 새 채팅 오픈
- `navigate_page(pageId, type="url", url="https://gemini.google.com/app", ignoreCache=True)`
- `take_snapshot(pageId)`으로 `button "업로드 및 도구"`의 `uid` 확인.

### Step 2. Image 1 첨부 (`25초` 컷 · 검색창 입력 금지)
1. **업로드 창 열기**: `click(업로드 및 도구, includeSnapshot=True)` → `click(menuitem "Drive에서 파일 추가", includeSnapshot=True)`
   - *(스냅샷에 `progressbar "로딩 스피너"`만 보이면 1회 `take_snapshot(pageId)` 추가 호출)*
2. **0토큰 Python 필터로 `uid` 1초 추출 (전체 스냅샷 읽기 금지)**:
   ```powershell
   py -3 -c "f=open(r'<snapshot_output.txt>', encoding='utf-8'); [print(l.strip()) for l in f if any(k in l for k in ['01_Image1', '룩북메인모델', '02_Image2', '행거샷'])]"
   ```
3. **1-Shot 즉시 삽입 (`2초`)**: 추출된 `01_Image1_...` (또는 `룩북메인모델<N>.png`) `option`의 `uid`에 **`click(pageId, uid, dblClick=True, includeSnapshot=True)`**를 실행한다. (별도의 `삽입` 버튼을 찾지 않는다.)

### Step 3. Image 2 첨부 (`18초` 컷 · 검색창 입력 금지)
1. **업로드 창 열기**: `click(업로드 및 도구, includeSnapshot=True)` → `click(menuitem "Drive에서 파일 추가", includeSnapshot=True)`
2. **0토큰 Python 필터로 `uid` 1초 추출**: 저장된 스냅샷 파일에서 `02_Image2_...` (또는 행거샷 파일명) `option`의 `uid`만 즉시 추출한다.
3. **1-Shot 즉시 삽입 (`2초`)**: 해당 `uid`에 **`click(pageId, uid, dblClick=True, includeSnapshot=True)`**를 실행한다.

### Step 4. 2장 첨부 검증 및 1~N컷 연속 생성 (재첨부 0회 · 0초)
1. **첨부 검증**: 스냅샷에서 `button "첨부파일 닫기"`가 **정확히 2개**인지 확인한 뒤, `textbox "Gemini 프롬프트 입력"`에 1번 컷 프롬프트를 `fill`하고 `button "메시지 보내기"`를 클릭한다.
2. **합격 시 연속 생성 (재첨부 `0초`)**: 1번 컷 합격 시 `button "원본 크기 이미지 다운로드"` 클릭과 동시에 **같은 채팅 입력창**에 2번 컷 프롬프트 `fill` + `press_key("Enter")`를 한 턴에 묶어 실행한다. (2~N컷은 이미지를 다시 첨부하지 않는다.)
3. **불합격 시 강제 리셋**: 사용자가 불합격 판정하면 기존 채팅에서 수정하지 않고 즉시 `navigate_page(url="https://gemini.google.com/app", ignoreCache=True)`로 새 채팅을 연 뒤 Step 2~3(`43초` 컷)으로 재첨부한다.
